# Memory Game

Игра «Найди пару» на чистом JavaScript + Vite.

16 карточек, 8 пар картин известных художников: Писсарро, Моне, Ван Гог,
Вермеер, Хокусай, Климт, Дали, Мунк.

## Возможности

- Перемешивание карточек при каждой новой игре
- Счётчики ходов и найденных пар
- Модальное окно победы с итоговым числом ходов
- Таблица лидеров (топ-10) с сохранением в localStorage
- Тёмная рубашка карточек, 3D-переворот
- Адаптивная вёрстка

## Запуск

Требуется Node.js 18+.

    npm install
    npm run dev

Открой http://localhost:5173

Или вместо этого открой https://memory-game-4x4.netlify.app

## Сборка

    npm run build
    npm run preview

## Стек
